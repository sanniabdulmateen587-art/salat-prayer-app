# SALAT — Your Complete Prayer Companion

Modern Islamic prayer app with accurate offline prayer times, Qiblah, Wudu & Salah guides, tracker, and more.

**Live:** https://salat-prayer-app.netlify.app

## Features
- Accurate prayer times (adhan-js, offline)
- Next prayer countdown
- Qiblah compass
- Wudu & Salah step-by-step guides
- Post-Salah Adhkar & digital Tasbih
- Prayer tracker with streaks
- Tahajjud night prayer times
- Dark/light mode, PWA-ready

## Local
Open `index.html` via a static server, or deploy the folder to any static host.
